# 中期答辩问题：阶段进度表

## 1. 文档目的

本文档只保留“怎么推进”的内容，便于执行、拆任务、汇报进展。

建议将后续工作划分为 **5 个阶段**。前 3 个阶段解决“平台能不能做论文实验”，后 2 个阶段解决“实验能不能形成可信结论”。

## 3. 各阶段详细工作说明

## 3.1 阶段 0：现有平台整理与基线固化

### 阶段目标

先把当前已经完成的内容固化下来，防止后续大改时丢失已有成果。

### 需要完成的工作

- 统一 `PMAP` / `PMAP_ACK` 的任务配置入口与协议字段
- 清理分析页、任务页、日志字段中的命名不一致问题
- 固化当前可用场景：
  - `baseline_d2z`
  - `pmap_ack_baseline`
  - `pmap_ack_attack_drop_ack`
- 增加最小回归测试，覆盖：
  - ACK 正常提交
  - 首次去同步后恢复
  - 会话统计与时间线解析
- 确认当前 README、全景介绍、改进计划文档一致

### 阶段产出

- 一套“稳定基线版本”
- 一套可复现实验任务
- 最小回归测试集

### 完成标志

- 当前平台可以稳定复现实验
- 去同步恢复链路已不再有解析类 bug
- 文档和代码状态一致

## 3.2 阶段 1：平台动态性增强

### 阶段目标

解决“这只是通用协议仿真器，不是无人机网络仿真”的核心质疑。

### 需要完成的工作

- 增加蜂群规模配置能力：
  - 10 UAV
  - 30 UAV
  - 50 UAV
  - 100 UAV
- 设计上层运动调度器，而不是只靠简单 waypoint 播放
- 支持以下运动模式：
  - 轨迹巡检
  - 编队起飞/群飞
  - 高速转场
- 将认证触发从固定时刻改为“任务/位置驱动”：
  - 覆盖边缘触发
  - 切换窗口触发
  - 任务启动并发触发
- 让链路状态与位置关系显式绑定：
  - 距离
  - 边缘区域
  - 丢包 / 失联窗口

### 阶段产出

- 动态运动调度模块
- 大规模 UAV 场景模板
- 位置驱动认证触发机制

### 完成标志

- 不同 UAV 数量下可稳定运行
- 日志里能看出由位置/任务事件触发认证
- 可以构造“边缘触发 -> 丢 ACK -> 恢复”的完整动态过程

## 3.3 阶段 2：多协议框架扩展

### 阶段目标

解决“只有一个协议无法对比”的问题。

### 需要完成的工作

- 规范协议抽象接口：
  - 初始化
  - 消息处理
  - 状态更新
  - 日志记录
- 保持 `PMAP` 与 `PMAP_ACK` 的现有能力
- 增加 1 个静态/预共享身份基线协议
- 增加 1 个高开销公开密钥协议（代表性实现）
- 统一多协议日志字段，保证比较时字段对齐
- 在前端增加多协议实验场景映射能力

### 阶段产出

- 多协议统一运行框架
- 多协议可比实验配置
- 协议对照清单

### 完成标志

- 同一场景下至少能切换 3-4 个协议
- 后端能对不同协议输出统一格式指标
- 前端能选择协议并查看对应结果

## 3.4 阶段 3：指标与图表输出

### 阶段目标

解决“只有日志，没有可量化数据与图像”的问题。

### 需要完成的工作

- 扩展现有指标体系，补充：
  - `State Mismatch Rate`
  - `Recovery Completion Ratio`
  - `Protocol-Step Failure Breakdown`
  - `Re-authentication Cost`
  - `Tail Latency`
- 增加结果导出：
  - CSV
  - JSON
- 增加自动绘图脚本，支持：
  - `Success Rate vs Distance`
  - `CDF of Authentication Delay`
  - `Failure Rate vs UAV Velocity`
  - `Success Rate vs Number of UAVs`
  - `Communication Overhead vs Protocol`
- 补充批量实验运行脚本：
  - 参数扫描
  - 自动落盘
  - 自动汇总

### 阶段产出

- 论文级图表生成脚本
- 对比实验数据包
- 标准化结果目录

### 完成标志

- 不需要手工数日志即可生成图表
- 同一实验可重复导出相同统计结果
- 图表可直接进入论文和答辩 PPT

## 3.5 阶段 4：主实验收敛与论文结果固化

### 阶段目标

形成真正可用于论文和答辩的最终结果。

### 需要完成的工作

- 跑通主实验 A：轨迹驱动的边缘恢复实验
- 跑通主实验 B：大规模并发蜂群认证实验
- 跑通补充实验 C：高速移动下的突发失联恢复
- 做参数扫面与统计复核：
  - 多次重复实验
  - 不同随机种子
  - 结果方差检查
- 对每个主结论补足：
  - 机制解释
  - 协议对比理由
  - 局限性说明
- 将实验结果整理为：
  - 论文实验章节
  - 答辩结果页
  - 补充材料

### 阶段产出

- 最终实验图表包
- 论文主实验结论
- 中后期答辩演示材料

### 完成标志

- 可以明确回答“为什么 PMAP_ACK 更适合动态 UAV 网络”
- 可以明确回答“为什么 PMAP 系列在蜂群场景下有优势或局限”
- 可以用图表和统计结果支撑全部主要论点
