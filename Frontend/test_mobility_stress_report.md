## 解决方案

### 环境要求
要运行完整的仿真，需要：
1. **可写文件系统**：ns3模拟器需要写入构建日志
2. **ns3环境**：已安装并配置ns3模拟器
3. **Python环境**：已安装所有依赖包

### 运行步骤
1. **启动后端服务器**：
   ```bash
   cd /home/zhang/UAV/Backend
   python3 app.py
   ```

2. **启动前端服务器**：
   ```bash
   cd /home/zhang/UAV/Frontend
   npm start
   ```

3. **访问前端界面**：
   - 打开浏览器，访问 http://localhost:3000
   - 在"创建新仿真任务"部分选择"机动应力测试"场景
   - 调整网络规模、密度和GM3D应力档位
   - 点击"创建任务"按钮

4. **运行仿真**：
   - 在"任务管理"部分找到创建的任务
   - 点击"运行"按钮启动仿真
   - 等待仿真完成

5. **分析结果**：
   - 在"分析数据源"部分输入任务ID
   - 查看仿真结果和性能指标
